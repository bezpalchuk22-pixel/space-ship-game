# Результати навантажувального тестування

## 1. Мета тестування

Мета тестування — оцінити продуктивність WebSocket-сервера гри Space Ship Game за різної кількості одночасно підключених клієнтів.

Перевірялися:
- кількість отриманих ігрових snapshot;
- частота отримання snapshot одним клієнтом;
- середній RTT;
- RTT на рівнях p50, p95 та p99;
- вхідний і вихідний мережевий трафік.

## 2. Методика тестування

Навантажувальний тест виконувався автоматизованим скриптом `server/src/bench/websocket-load.ts`.

Перевірялися чотири конфігурації: 8, 16, 32 та 64 одночасні клієнти.

Для кожної конфігурації використовувалися:
- час прогрівання — 2 секунди;
- час вимірювання — 10 секунд;
- надсилання ігрових команд приблизно кожні 33 мс;
- WebSocket-з'єднання з локальним тестовим сервером.

## 3. Результати

| Показник | 8 клієнтів | 16 клієнтів | 32 клієнти | 64 клієнти |

| RTT average, мс | 3,02 | 3,71 | 4,91 | 5,90 |
| RTT p50, мс | 3,09 | 3,79 | 3,73 | 5,52 |
| RTT p95, мс | 4,50 | 7,31 | 11,40 | 11,62 |
| RTT p99, мс | 6,64 | 8,12 | 15,37 | 12,63 |

| Вихідний трафік, KB/s | 15,70 | 32,73 | 68,32 | 139,81 |

## 4. Аналіз результатів

За результатами тестування сервер підтримував частоту отримання snapshot близько 30 разів на секунду на одного клієнта в усіх чотирьох конфігураціях.

При збільшенні кількості клієнтів із 8 до 64 середній RTT зріс із 3,02 до 5,90 мс. Значення p99 для 64 клієнтів становило 12,63 мс.

Мережевий трафік закономірно збільшувався зі зростанням кількості підключень. Для 64 клієнтів зафіксовано вхідний трафік 7737,85 KB/s та вихідний трафік 139,81 KB/s.

## 5. Висновок

Навантажувальне тестування підтвердило, що реалізований WebSocket-сервер здатний обробляти до 64 одночасних тестових клієнтів у локальному середовищі зі збереженням частоти оновлення snapshot близько 30 Hz.

Отримані результати свідчать про стабільну роботу симуляції та помірне зростання затримки при збільшенні навантаження.

Варто враховувати, що тест проводився локально. Реальна затримка під час гри через інтернет залежатиме від мережевого з'єднання, відстані до сервера та характеристик хостингу.
